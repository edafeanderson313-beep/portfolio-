ANDERSON EDAFE — PORTFOLIO WEBSITE

FILES
- index.html: page content
- style.css: visual design and responsive layout
- script.js: mobile navigation and current year

HOW TO OPEN
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Edit the text in index.html when you need to update your information.

BEFORE PUBLISHING
- Check that your phone number and email are correct.
- Add a professional photo only if you want one.
- Add your GitHub profile and LinkedIn profile when available.
- Add screenshots and live links for projects only after they are working.
- Update project descriptions to reflect exactly what you completed.
- Do not describe ongoing AI automation learning as completed professional experience.

PUBLISHING
You can publish this static website using GitHub Pages:
1. Create a GitHub repository.
2. Upload index.html, style.css and script.js to the repository root.
3. Open repository Settings > Pages.
4. Choose deployment from the main branch and root folder.
5. Save and wait for GitHub Pages to publish the site.
